## Описание проекта
Программа представляет собой двумерную космическую аркадную игру «Астероиды» (RiceRocks) с графическим интерфейсом на базе библиотеки `tkinter` и обработкой растровых спрайтов через `Pillow`. В проекте реализованы тайловая анимация изображений (работа двигателей корабля и многокадровые взрывы), тороидальная геометрия игрового поля, физика инерции с сопротивлением среды, а также система динамического спавна вращающихся астероидов. Архитектура приложения построена по объектно-ориентированному принципу с разделением на глобальную конфигурацию, математическую модель, тайловый рендерер и панель индикации событий.

## Функциональные возможности
### Основной функционал
-  Управление космическим кораблем: вращение вокруг центра, ускорение по вектору ориентации и торможение за счет сопротивления среды
-  Тайловая смена спрайта корабля при включении и выключении маршевых двигателей
-  Неподвижный фон туманности и динамический полупрозрачный слой астероидов, непрерывно движущийся влево
-  Тороидальная геометрия игрового поля (плавный переход объектов через противоположные границы экрана)
-  Генерация астероидов со случайной линейной и угловой скоростью вращения
-  Выстрелы ракетами из носа корабля с ограниченным временем жизни и тайловая анимация взрыва (16 кадров) при попадании
-  Интерактивная заставка `RiceRocks`, запускающая игру строго по клику мыши в пределах рамки заставки

### Дополнительный функционал
-  Боковая панель мониторинга событий клавиатуры (`Key`) и координат кликов мыши (`Mouse`) в реальном времени
-  Автоматическая процедурная генерация растровых PNG-спрайтов и тайловых листов в папку `assets/` при первом запуске
-  Набор модульных тестов (`unittest`) для проверки тороидальной геометрии, времени жизни ракет и коллизий

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone [https://github.com/Depshen/3.4_Asteroids.git](https://github.com/Depshen/3.4_Asteroids.git)
cd 3.4_Asteroids
```

### 2. Создание и активация виртуального окружения
**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск программы
**Windows:**
```bash
python main.py
```

**macOS / Linux:**
```bash
python3 main.py
```

### 5. Управление в игре
- **Клик левой кнопкой мыши по заставке `RiceRocks`** — старт новой игры
- **Стрелки Влево `←` / Вправо `→`** — вращение корабля против / по часовой стрелке
- **Стрелка Вверх `↑`** — включение двигателя (ускорение по направлению носа корабля)
- **Space (Пробел)** — выстрел ракетой из носа корабля

## Структура проекта
```text
3.4_Asteroids/
├── .gitignore                   # Исключения Git (__pycache__, *.pyc; папка venv сохранена)
├── README.md                    # Документация проекта с инструкцией по запуску
├── requirements.txt             # Зависимости проекта (Pillow)
├── main.py                      # Точка входа в программу
├── assets/                      # Растровые PNG-спрайты и тайловые ленты анимации
├── src/
│   ├── __init__.py              # Инициализация пакета src
│   ├── config.py                # Глобальные константы и параметры физики игры
│   ├── app.py                   # Класс App (главное окно, таймеры, обработчики событий)
│   ├── models/
│   │   ├── __init__.py
│   │   └── game_model.py        # Классы ImageInfo, Ship, Sprite, GameModel (физика и логика)
│   ├── renderers/
│   │   ├── __init__.py
│   │   └── renderer.py          # Класс Renderer (генерация тайлов, вращение и отрисовка)
│   └── widgets/
│       ├── __init__.py
│       └── controls.py          # Класс ControlPanel (индикаторы Key и Mouse)
└── tests/
    ├── __init__.py
    └── test_model.py            # Модульные тесты математики и взаимодействий объектов
```

**Обоснование выбранной структуры и назначение модулей:**
Проект разделен на независимые модули в соответствии с принципами ООП и паттерном MVC:
- `main.py` — точка входа, запускающая главное окно `tkinter`.
- `src/config.py` — централизованное хранилище всех глобальных параметров игры (размеры поля, коэффициенты трения, скорости, геометрия тайлов).
- `src/models/game_model.py` — математическая модель: описывает метаданные тайлов (`ImageInfo`), физику корабля (`Ship`), универсальный класс космических объектов (`Sprite`) и контроллер состояния игры (`GameModel`).
- `src/renderers/renderer.py` — графический движок, отвечающий за генерацию и чтение PNG-спрайтов, кадрирование тайловых анимаций и рендеринг сцены на `Canvas`.
- `src/widgets/controls.py` — боковая панель интерфейса для отображения нажатых клавиш и координат кликов мыши.
- `src/app.py` — связующий класс приложения, управляющий главным циклом анимации и пользовательским вводом.
- `tests/test_model.py` — модульные тесты для автоматической проверки физики без запуска GUI.
